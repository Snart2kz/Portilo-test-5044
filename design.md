 # Loan Hacheme — Portfolio

## Direction
Studio d’ingénierie éditorial : fond ivoire #f5f4ef, encre #24251f, orange #ef5b32, vert disponibilité #719576. Manrope pour les titres, Poppins pour le texte, IBM Plex Mono pour les repères, polices locales.

Grille 1280px, marges desktop 64px / mobile 22px, titres imposants, filets fins et espace généreux. Hero asymétrique avec diagramme d’architecture animé et interactif. Entrée séquencée, scroll reveals, respect du mouvement réduit.

## Contenu et interactions
Site web francophone à page unique : accueil, 6 concepts filtrables, expertise architecture / data / frontend / IA, parcours et contact. Détails des concepts en dialogue, liens externes réels. Les concepts sont réalisés par Loan selon sa confirmation ; aucun projet client du catalogue. Vignettes originales du catalogue.

CV original téléchargeable ; contact mailto, GitHub, LinkedIn. Aucun formulaire fictif, aucune table ou nouvelle API nécessaire.

## Fichiers
Frontend dans packages/web/src/web, données dans lib/portfolio.ts, diagramme et page dans components, styles.css global. Assets uniquement dans public. Web uniquement ; stack gérée conservée.
